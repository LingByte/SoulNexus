## 4. 核心卖点（可直接上官网）

### 4.1 五大能力卡

1. **实时语音对话**  
   WebSocket / WebRTC 低延迟语音会话，支持级联 ASR→LLM→TTS，以及可选多模态 Realtime。

2. **企业知识库**  
   文档入库、混合检索与引用回传，让助手回答可追溯、可运营。

3. **助手与工作流**  
   可视化配置助手、工具绑定、MCP 与工作流编排，一站落地业务场景。

4. **多租户与治理**  
   租户隔离、RBAC、API Key（AK/SK）、审计与用量视图，满足企业级治理。

5. **声纹与音色**  
   声音克隆、声纹识别与说话人上下文，打造可辨识的品牌语音体验。

### 4.2 产品全景四点

- 可视化工作流与插件市场  
- 助手调试台与链路指标  
- 音色克隆与声纹管理  
- JS 模板与多端接入（网页 Embed / 桌宠）

### 4.3 技术亮点三句

- **高并发与低延迟**：异步架构与可观测管线，保障语音会话稳定体验。  
- **安全与治理**：多租户 RBAC、加密传输与审计日志。  
- **开放可扩展**：MCP、工作流插件与模型路由可插拔。

## 7. 核心用户旅程（可做成官网「三步上手」）

1. **配置助手** — 选模板 → 配置 ASR / TTS / LLM / 知识库 / MCP → 发布 → Debug。  
2. **接入知识** — 创建知识空间 → 上传文档 → 索引 → 召回测试与运营分析。  
3. **对外交付** — 网页 Embed / 挂件市场 / 桌宠挂载；或 API / 工作流触发。

## 9. 官网文案禁忌与合规注意

1. 不要承诺「完整计费 / 支付 / 套餐价格」除非商务方案已定。  
2. 不要宣传「SIP / 传统呼叫中心替换」——产品是 Voice Session / Dialog，不是电信交换机。  
3. 不要把规划文档（`feature-recommendations.md`）当已发布功能写进官网。  
4. 声音克隆、Realtime、向量库等依赖第三方 Key / 基础设施，文案宜用「支持对接主流供应商」。  
5. License 为 AGPL-3.0：若面向商业客户，官网需准备「商业授权 / 联系商务」说明，避免合规误解。  
6. 截图请使用当前控制台真实界面（工作流、调试、音色、挂件），避免 mock 过度包装。
